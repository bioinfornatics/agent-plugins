# Agent Creator evaluation fixtures

Immutable fixtures for `agent-creator` scenarios. Copy them to an isolated sandbox before editing, installation, or evaluation.

- `invalid-agent.md`: unsupported `tools` and `permissionMode` fields.
- `role-comparison/baseline/security-reviewer.md`: valid generic baseline role.
- `role-comparison/current/security-reviewer.md`: valid evidence-focused improved role.
- `role-comparison/evals.json`: concrete delegated tasks used for paired evaluation.
