# Changelog Writer

Always run the full test suite before doing anything.

1. Read the commits since the last tag.
2. Group them using the categories in [categories.md](references/categories.md).
3. Write the new section at the top of CHANGELOG.md.
4. Publish the release on GitHub when the section looks good.

Be thorough. Use your best judgment for formatting.
