# Plugin Creator

Orchestrates whole-plugin authoring, manual format review, MCP integration and
component routing. [SKILL.md](SKILL.md) owns intent selection, common safety,
host/identity distinctions and the delivery contract, including partial/blocked work.

## Navigation

- [Portable format](references/portable-plugin-format.md) and
  [tolerant versus strict review](references/portable-conformance.md): common published
  Agent Plugins 1.0.0 package review, not host activation proof.
- [Author or migrate](references/authoring-workflow.md): approved destination,
  preserved originals, component routing and unmapped items.
- [Goose integration](references/goose-plugin-format.md): load before integration
  selection/change **only for a Goose target or existing Goose migration/review**.
  Native hooks route to hook-creator with [current contract/evidence](references/goose-target-compatibility.md).
- [Archive](references/archive-workflow.md): contents, integrity and prerequisites,
  not implicit installation, behavioral evaluation or publication.
- [Installation review](references/installation-diagnostics.md): selected host's
  verified current guidance and separate authorization.
- Requested evaluation/report work: follow the **available skill-creator handoff in
  SKILL.md**, resolving its guidance from its loaded root rather than a presumed
  sibling installation. That owner supplies exact commands/defaults, configured
  candidate/judge provenance, monitoring and export/HTML safeguards. History/inspect
  remain read-only; honor full versus explicitly partial completion boundaries.
- [Scenario suite](evals/evals.json): short natural requests, supported fields and
  neutral inputs. Suite import/dry-run is static preparation, not behavior evidence.

## Boundaries

This is an instruction Skill. Retired creator commands/native executables are not
fallback tools. Shared standalone Skill validation/evaluation does not validate
whole-plugin format, prove activation or grant release approval. Defaults are not
changed by this routing: use tool defaults, override only explicitly requested
values, and ask only for required values without defaults. Authoring does not
implicitly authorize models, installation, credentials, network or publication.

Active host guidance targets current stable releases and official documentation.
Exact observed versions, declared support and missing proof belong in the
[compatibility matrix](references/compatibility-matrix.md); documented capability
is not tested integration. Historical sources/evidence remain retained, not alternate
ordinary workflows. See SKILL.md for configured versus observed identity limits.
