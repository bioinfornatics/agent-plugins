## Deterministic oracle and missingness

Authoring runner has nine actual subprocess checks: echo with spaces/Unicode/metacharacters/empty argv; status-7 failure; status-2 unknown operation; traversal, absolute and missing-entry refusals; bad hash; symlink leaf escape with a valid outside hash; symlink parent. Empty PATH and cwd outside copied component rule out incidental cwd/PATH dependence. Assertions are hardcoded observable outputs, not a duplicated containment algorithm. Input hashes are compared before/after. The runner is not supplied as task data or silently enforced by the CLI.

Static JSON/links/import/input checks establish preparation only. Contextual designs/routing need independent semantic review of a frozen response, and any claimed effects need tool/artifact proof. No scored comparison, paid campaign, native target run, Rust/Python execution, signal test or host installation is recorded by authoring. Mark missing evidence inconclusive rather than turning it into success.
