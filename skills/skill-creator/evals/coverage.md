## Unresolved retained execution acceptance

[Pending execution specifications](pending-retained-execution.json) retain IDs 8–10
as natural **Inspect / Resume / Grade-and-export** requests, not how-to questions.
They are deliberately outside exact `evals/evals.json` discovery. Their identity
tokens are unbound, not fabricated UUIDs or imaginary ready paths. Do not run them
or count them as active coverage until verified fixture metadata binds real paths,
campaign/attempt IDs and separate model authority where required.

Current app tests inspected: `tests/evaluation/history.test.ts`,
`tests/execution/registry.test.ts`, `tests/evaluation/export.test.ts`. Real public
seams include `prepareEvaluation`, `SqliteEvaluationStore.begin/start/finish/close`,
`SqliteEvaluationHistory.inspect`, `SqliteVerifiedAttemptReader`, and judgment
storage. Native schema-v2 construction is feasible locally without models, but
`begin` generates a random campaign UUID and archives/checkpoints are bound to
absolute campaign output locations. History tests create temporary registries;
they do not supply a portable retained fixture. No relocatable generator or
verified fixture binding was completed in this one-pass instructions slice.
SQLite extensions are **not** prohibited by declared-input policy; reserved
configuration names/entrypoints are. Neutral archives could be inputs. These facts
do not make unbound copies ready. History/inspect, interrupted resume and retained
grading/export execution remain **unresolved acceptance**, not completed coverage.

## Evidence limits

- Cases 6–7 now request actual nested no-model preparation, including authorized
  authoring of entrypoints. Inert source inputs are never represented as active
  target paths. External CLI capability must be available equally to both arms.
- Case 11 already supplies a complete current-format synthetic rendering fixture;
  it is a separately executable useful journey, not a replacement for registry
  execution or authentic provider evidence.
- Instruction/static verification, nested preparation, model execution, grading,
  export integrity, browser behavior and useful outcomes require separate proof.
  No behavioral evaluation, paid grading, compatibility or independent acceptance
  is claimed here. Default model selection omits overrides.
- Broad isolation/security, real providers, accessibility, other hosts, installation,
  publication and monetary-cap enforcement remain uncovered.

assets remain retained outside active discovery. See preparation for the current
