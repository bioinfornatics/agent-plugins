# Evidence boundaries

Current standalone `validate` establishes only recorded Skill-format findings.
Suite loading/dry-run establishes preparation, not execution. History/inspect
establish stored state and evidence presence, not hashes or scores. Explicit
export reverifies selected archives and bindings, not calibrated judge quality.
Report creation establishes a generated HTML file; browser/manual accessibility
and behavioral effectiveness are separate proof obligations.

No current `verify` command, release receipt, threshold policy or automatic
release eligibility is supplied.
Use [current evaluation](evaluate-workflow.md) for authorized execution and
[report review](review-viewer.md) for generated-export review.
